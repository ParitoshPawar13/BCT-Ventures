# Task 5 Demo Script

Use this as the spoken script for the required short demo.

## Scene 1 — Overview

“This is AdPilot, a standalone Meta Ads Manager-inspired campaign management prototype. The hierarchy is Campaign → Ad Set → Ad.”

## Scene 2 — Create campaign

“First I create a campaign and provide the required objective, budget type and budget.”

## Scene 3 — Add ad set and ad

“Inside the campaign I can manage multiple ad sets. Each ad set has targeting, scheduling and budget settings. Inside an ad set I can manage individual ads with creative, copy, CTA and landing page.”

## Scene 4 — Validation

“Validation happens while I edit the form. If I remove the headline or creative, the application immediately displays an inline error and the campaign readiness indicator shows that the campaign is not ready.”

## Scene 5 — Launch protection

“If I click Launch while the campaign has issues, the application blocks the action and shows exactly what must be fixed.”

## Scene 6 — Duplication

“I can duplicate a campaign, ad set or ad with one click. The duplicate receives new IDs and can be edited independently.”

## Scene 7 — Bulk edit

“I can select multiple ads and change a common field such as CTA or status in one action. The same pattern is available for ad sets.”

## Scene 8 — Comparison

“Compared with a Google Sheets workflow, the UI makes the hierarchy visible, gives immediate validation, and makes duplication and bulk actions easier to discover. The trade-off is greater application-development effort.”

## Closing

“The prototype is intentionally standalone and does not launch real Meta campaigns. It demonstrates the requested workflow, validation and management experience without requiring Meta API credentials.”
